# 6001CMD Machine Learning Coursework 1

This repository contains the Python source code and analysis evidence
used for the 6001CMD Machine Learning individual assignment.

## Dataset

Mudah Apartment Rental Dataset - Kuala Lumpur and Selangor

Dataset source:
https://www.kaggle.com/datasets/ariewijaya/rent-pricing-kuala-lumpur-malaysi/data

The dataset file is not included in this repository.
Place `mudah-apartment-kl-selangor.csv` inside the `data/` directory
before running the scripts.

## Project Structure

- `task1/` - Dataset overview and characteristics
- `task2/` - Learning paradigm evidence
- `task3/` - Data quality analysis and visualisations
- `task4/` - Data preprocessing demonstrations
- `outputs/` - Generated figures and analysis outputs

## Requirements

- Python
- pandas
- NumPy
- Matplotlib
- SciPy
- scikit-learn
